# Portfólio Web Dinâmico — Canes Solution

Portfólio profissional **single-page**, responsivo e acessível. Todo o conteúdo é
renderizado no cliente com HTML5, CSS3, JavaScript puro e Bootstrap 5 — **sem
backend, sem banco de dados relacional e sem construtores de site**.

O projeto inclui:

- Apresentação pessoal (nome, foto, bio, hard skills e soft skills).
- Seções temáticas sobre 4 áreas do conhecimento e 4 tendências tecnológicas.
- Galeria com 4 projetos (descrição, imagem, tecnologias e links).
- Formulário de contato que **salva no LocalStorage** e **dispara automação
  real via webhook** (JSON).
- **Painel administrativo oculto** para CRUD das mensagens, com seed de 20
  registros de teste e exportação em JSON.
